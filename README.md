# Loan Management System

This is a complete Loan Management System built using modern web technologies.

## Tech Stack

### Frontend
* **HTML**: Structure of the web pages.
* **Tailwind CSS**: A utility-first CSS framework for rapid UI development.
* **Angular (v19)**: A framework for building single-page client applications.
* **TypeScript**: A strongly typed programming language that builds on JavaScript, giving you better tooling at any scale.

### Backend
* **Node.js (Plain)**: The backend is built using plain Node.js to handle API requests, business logic, and database operations.

## How to run the project

### Backend
Navigate to the `back-end` directory and run:
```bash
npm start
```

### Frontend
Navigate to the `angular19-LMS` directory and run:
```bash
npm start
```
The frontend will be available at `http://localhost:4200/`.
